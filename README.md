# Alamount RPA

Windows için kurumsal RPA: belge okuma (Türkçe OCR), işe giriş verisi hazırlama, Mikro ERP masaüstü otomasyonu,
PCA analizi ve çok robotlu çalışma için web tabanlı **Kontrol Merkezi** (kuyruklar, zamanlamalar, şifreli kasa,
e-posta / Teams bildirimleri).

| Klasör | İçerik |
|---|---|
| `rpa/` | Kaynak kod, Robot Framework görevleri (`gorevler/`), kurulum betikleri, kılavuz ([`rpa/KULLANIM.md`](rpa/KULLANIM.md)) |
| `rpa/marka/` | Logo, simge, favicon |
| `rpa/testler/` | Uçtan uca Kontrol Merkezi testi |
| `.github/workflows/` | Windows derlemesi (`AlamountRPA.exe`), duman testleri ve sürüm yayını |
| `PCA_Example.ipynb` | Botun ilk sürümünün temel aldığı PCA analizi |

Hazır Windows paketi: **Releases** sayfasındaki `AlamountRPA_Windows.zip`.
